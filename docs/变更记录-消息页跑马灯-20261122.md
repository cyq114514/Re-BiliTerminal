# 变更记录：消息页快捷入口文字改跑马灯（2026-11-22）

## 背景

用户截图里消息页顶部四个快捷入口被截断成「回…」「收…」「消…」（带未读数后文字更长），
要求改成跑马灯。

顶栏标题「消息」本身只有两个字、不溢出，改成跑马灯没有视觉效果；
且它的左侧箭头依赖 `app:drawableStartCompat`（AppCompat 属性），换成 `MarqueeTextView`
（直接继承 TextView）会丢图标，所以本次不动 `pageName`。

## 改动

`app/src/main/res/layout/activity_message.xml`：五个快捷入口文字由 `TextView`
换成 `com.RobinNotBad.BiliClient.ui.widget.MarqueeTextView`：

| id | 文案 |
|---|---|
| `reply_text` | 回复我的 |
| `at_text` | @我 |
| `like_text` | 收到的赞 |
| `setting_text` | 消息设置 |
| `system_text` | 系统通知 |

`MarqueeTextView` 构造时调 `applyTo()`：`setSelected(true)` + `MARQUEE` + 单行 + 循环 3 次，
并受实验室「文字跑马灯」开关（`marquee_enable`，默认开）控制；关闭时退化为末尾截断。
`MessageActivity` 里的 `((TextView) findViewById(...))` 强转不受影响（子类）。

## 验证

- 编译 `:app:assembleRelease` 通过。
- 真机（PJZ110，1440×3168）进入消息页后 uiautomator 抓取：

```
text="回复我的" resource-id=".../reply_text" class="android.widget.TextView"
  focusable="true" selected="true" bounds="[160,358][638,417]"
```

`selected="true"` + `focusable="true"` 说明 `MarqueeTextView.applyTo()` 已生效；
`class` 显示 `android.widget.TextView` 是 uiautomator 取 `getAccessibilityClassName()`
的结果，自定义子类不会改变该值。

- **滚动动画未取得真机截图**：当前手机宽度 478px 大于「回复我的」文字宽度（约 180px），
  不满足溢出条件，Marquee 不滚动（符合预期）；把 `wm size` 缩到 540×1200 制造溢出时，
  系统在配置变更后把 MessageActivity 销毁回桌面，没有抓到滚动帧。
  文字溢出的窄屏设备（手表/词典笔）上会滚动。

## 回滚

`git checkout -- app/src/main/res/layout/activity_message.xml` 即可。

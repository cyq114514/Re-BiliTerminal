# 番剧分区移植：阶段一源码审计对照报告

> 2026-11-04。审计对象：`/tmp/PiliPlus`（master 浅克隆）与本工作区 Re-BiliTerminal 1.2.8。
> 全程只读，未修改任何代码，未对线上接口做运行验证。

## 核心结论

**不需要从零移植。本仓库已存在一套完整但未接线的番剧分区**（`BangumiActivity` 新番/追番/索引三页签 + 全部 API + 详情选集播放），
真正要做的是：注册 Activity、挂菜单入口、补齐错误态/空态/竞态、按 PiliPlus 的 condition 接口升级筛选。

PiliPlus 当前是 **PGC/OGV 混合状态**，并非整体迁移 OGV：

| 功能 | PiliPlus 当前实际 API |
| --- | --- |
| 番剧推荐、索引条件、索引结果、时间表 | 旧 PGC Web API（与本项目一致） |
| 详情、剧集、季度 | `/pgc/view/web/season`（与本项目一致） |
| 播放地址主请求 | **OGV `/ogv/player/playview`（需 WBI）** |
| OGV 遇 DRM 回退 | 旧 PGC `/pgc/player/web/v2/playurl`（本项目现行方案，未签 WBI，目前可用） |

## 所需 API 及凭证

| API | 用途 | 凭证 |
| --- | --- | --- |
| `GET /pgc/web/season/index/result` | 索引结果（现行） | 无 WBI，Cookie 可选（NetWorkUtil 自动带） |
| `GET /pgc/season/index/condition?season_type=1&type=0` | 动态筛选条件（拟新增） | 无 WBI，Cookie 可选 |
| `GET /pgc/season/index/result` | 动态筛选结果（拟新增，condition 的 field/keyword 展开为 query） | 同上 |
| `GET /pgc/web/timeline?types=1&before=7&after=7` | 新番时间表（现行） | 无 WBI，Cookie 可选 |
| `GET /x/space/bangumi/follow/list` | 追番列表（现行） | **必须登录** |
| `GET /pgc/view/web/season`、`/pgc/web/season/section` | 详情/选集（现行） | Cookie 可选 |
| `GET /pgc/player/web/v2/playurl` | 播放（现行，不动） | Cookie 可选，会员内容需登录 |

不硬编码任何 Cookie/SESSDATA；全部走 `NetWorkUtil` 全局请求头。

## 入口方案

**推荐方案 A：菜单新增独立「番剧」格**（推荐之后）。符合现有导航、自动获得排序/恢复能力。
代价：菜单多一格；老用户自定义排序会把新入口补到末尾。
方案 B（备选）：把现有「时间线」入口升级为「番剧」（新番页签与原时间线同源），菜单格数不变，但失去独立 TimelineActivity 入口。
不推荐在推荐页顶部强加 Tab：首页不是 ViewPager，改造面大且压缩手表首屏。

## Android 4.4+（minSdk 19）兼容性风险

- 网络/图片必须走 `NetWorkUtil`/Glide 封装（API≤22 TLS 已适配），禁止自建 OkHttpClient。
- 无 coreLibraryDesugaring：禁用 `java.time`、stream、`List.of` 等，沿用 `SimpleDateFormat`/`ArrayList`。
- 颜色/tint 用 ContextCompat/DrawableCompat；vector 用 `app:srcCompat`。
- 筛选行数控制：新增年份/季度筛选放「更多筛选」`AdaptiveDialog`，不加常驻行。
- 分页必须 loading 防重入 + 失败页码回滚，避免弱网请求风暴。

## 已知接口迁移风险

- 播放：本项目旧 PGC v2 目前可用（1.2.0fix 验证）。PiliPlus 已转 OGV 主请求，说明旧接口存在退役风险；**本期不动播放链路**，若未来失效，按 PiliPlus `video.dart:215-320` 的 OGV 主 + PGC 回退方案迁移（需 WBI，项目已有 `ConfInfoApi.signWBI`）。
- 索引：本项目现行 `/pgc/web/season/index/result` 与 PiliPlus `/pgc/season/index/result` 路径不同，接入 condition 前需真机验证两个端点当前均可用，不可用则回退保留硬编码筛选，不伪造筛选效果。
- 详情入参是 media_id；索引项缺 media_id 时不能把 season_id 当同义字段，需反查或跳过。

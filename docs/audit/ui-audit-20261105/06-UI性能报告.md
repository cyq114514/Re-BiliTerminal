# Re-BiliTerminal UI 性能与实现质量报告

> 审计基线：1.2.8 · 只读静态分析 · 2026-11-05
> 结论先行：**图片管线与生命周期管理是这个项目做得最好的部分**；性能问题集中在「列表绑定期的重复 inflate」「全量 notify」「少量空转定时器」三处，均为 P2/P3，无 P0。

## 1. 图片加载（评级：优）

`CustomGlideModule` + `GlideUtil` 全应用统一走 Glide：
- 磁盘缓存 64MB 封顶（此前全线 NONE，`CustomGlideModule.java:33`）；内存缓存与位图池按 memoryClass/8 封顶并钳制 4~32MB，专为 64MB heap 手表设计（:39-47）。
- RGB_565 解码、磁盘缓存策略、滚动暂停请求、封面定比裁剪+圆角缓存复用统一收口（GlideUtil.java:82-187）。
- 图片管线凭据最小化（非 B 站域剥离 Cookie/Referer，`CustomGlideModule.java:74-93`）。
- 未发现列表图片错位（URL 作 key + placeHolder）；未发现大图不裁剪直载。

遗留：`VideoInfoFragment.java:692-694` 播放前主线程 `Glide.get(...).clearMemory()`（注释确认的手表内存取舍——代价是返回列表后全部图片重载，属有意为之，建议在规范中记录该取舍）。

## 2. 布局层级与过度绘制（评级：良）

- 静态扫描：138 个布局最大嵌套深度 7 层（activity_setting_theme_color / activity_setting_about / activity_message），无 10 层以上病态嵌套；普遍 RelativeLayout/FrameLayout 扁平结构。
- 过度绘制：新版美学全局常驻 `AmbientBackground` 装饰层 + 半透明卡片（#4D262626）——视觉设计即有 1-2 层全局 overdraw，手表 GPU 上可接受但需知情；代码已避免三层以上叠加（cardElevation=0 等注释显示有意识控制）。
- `AsyncLayoutInflaterX` 异步 inflate + 按帧驱动的淡入（BaseActivity.java:529-571）：低配手表上转场观感处理成熟。

## 5. 手势与输入（手表相关性高）

- 自研 `ScaleGestureDetector` mMinSpan=0（AOSP 默认有最小跨度），两指几乎贴住即触发缩放，小屏误触（ScaleGestureDetector.java:106）P3。
- 短视频右滑返回判定不排除进度条来源，拖进度≥20% 屏宽即触发返回（ShortVideoPlayerActivity.java:176-196）P1（交互层，详见问题报告）。
- 播放器 seekbar 显示后 200ms 禁用（防误触设计，代价是"刚显示就拖"无效）P3。

## 6. 主线程与 IPC 纪律（评级：优）

- `noSwipeThemeCache` 缓存 PackageManager IPC（BaseActivity.java:159-185）；badge/arrow ConstantState 缓存（ThemeApplier.java:47-50）；默认主题下 ThemeApplier 首行返回零开销（ThemeApplier.java:63）——三处都是注释明确的手表优化。
- 未发现 UI 线程网络/SP 大量 IO（SharedPreferencesUtil 为内存缓存模式）；未发现 for 循环内 findViewById 模式。

## 7. 资源与包体

- 疑似未引用：布局 2 个（activity_base、activity_simple_main_list）、drawable 8 个——release 有 shrinkResources 兜底，源码层面为维护噪音（清单见资源报告 §4）。
- 重复 drawable 内容 1 组 3 文件（background_card_borderless ≡ background_grey_cardview ≡ background_grey_setting）。
- resConfigs('zh') 已裁多语言；abiFilters armeabi-v7a/x86 已裁。

## 8. 结论

性能整改优先级：① TimelineAdapter 复用改造（手表列表绑定成本，P2）② 短视频手势冲突（P1，交互）③ 三处 Timer/空转小泄漏（P3 批量修）④ 全量 notify 改增量（P3）。其余项保持现状即可。

# Re-BiliTerminal UI 问题审计报告（P0–P3 全量清单）

> 审计基线：1.2.8（工作区含未提交改动，以工作区为准）· 只读审计 · 2026-11-05
> 覆盖：全部 102 个 Activity 类 / 21 个 Fragment / 弹窗体系 / 49 个 Adapter / 15 个自定义 View / 138 个布局 / 全部 values 资源。审计方式：静态代码审查（7 个域并行深查 + 全局静态扫描 + 关键 P1 人工复核）。
> **真机验证**：OnePlus PJZ110 仅完成启动级验证（见《09-真机视觉验证清单》），**手表结论未经实机验证**——影响判断处均已标注。

## 0. 统计总览

| 级别 | 数量 | 说明 |
|---|---|---|
| P0 | **0** | 未发现"主界面不可用/关键功能无法操作/布局严重错位/页面崩溃"级问题 |
| P1 | 23 | 功能失效、数据丢失风险、确认缺失、永久性空/转圈状态 |
| P2 | 55+ | 状态反馈缺失、适配缺陷、Token 双轨、交互一致性、主题覆盖缺口 |

问题编号规则：`域字母-序号`。A=主页/视频详情，B=播放器，C=搜索/番剧/直播/合集，D=用户/收藏/历史/本地，E=动态/消息/评论/图文/看图，F=设置/登录/引导/工具，G=通用组件/资源/主题引擎，X=跨页横切。
P0/P1 使用全字段记录；P2/P3 使用紧凑表（含全部必需字段的最小集）。「⚠️待验证」=证据充分但依赖运行时路径确认。

### A 域：主页与视频详情

**A-01 视频详情页加载失败永久空白**
- 页面：VideoInfoActivity/VideoInfoFragment ｜ 类别：状态完整性
- 表现：历史/取流上报返回 null 时 `return` 跳过 `onFinishLoad()`，内容视图（初始 GONE）永不显示，详情页停留在 2233 加载占位图
- 复现：弱网/接口异常打开任意视频详情
- 位置：`activity/video/info/VideoInfoFragment.java:306-320`（`if (playerData == null) return;` 在 onFinishLoad 调度之前）
- 影响：全部视频详情入口 ｜ 根因：提前 return 混入上报逻辑，吞掉 UI 恢复路径
- 修复：null/异常分支也必须调度 `onFinishLoad()`（或改用 finally）；占位图上加"点击重试"
- 验证：断网打开视频详情→应见错误/重试态而非永久加载图

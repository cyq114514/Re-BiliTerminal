## 1. 逐页验证步骤（每页 3-5 分钟）

通用动作（每页都做）：
1. 打开页面 → 检查首屏布局（顶栏标题正确？内容不越界？）
2. 上下滚动到底 → 再滚回顶部（滚动位置保留？图片错位？）
3. 点标题「返回上级」（本次专项：**每一页都试**）→ 是否返回？
4. 按系统返回键 → 行为与标题点击一致吗？
5. 断网（飞行模式）后进入/刷新 → 空态/错误提示可见？能重试？
6. 快速双击列表项 → 是否开出两个页面？

### 1.1 主页簇
- [ ] 菜单页：网格排布；消息/动态徽章数字；点标题（应显示来源页名）
- [ ] 推荐：下拉刷新；横屏开关打开后是否 3 列；emptyTip（断网冷启）
- [ ] 热门/排行/珍藏/热搜：**珍藏页滚动到底加载更多时再下拉刷新（P1 竞态复现：列表是否出现重复/错乱条目）**
- [ ] 时间线：点剧集条目（P1：代码中无点击监听，应无反应——确认是否与你预期一致）

### 1.2 视频簇
- [ ] 视频详情：进入后若加载失败（可用断网），是否**永久空白**（P1：GONE 卡死复现）
- [ ] 视频详情：有争议提示（argueMsg）的视频 → UP 区是否被顶出屏（P1：exclusiveTip 高度失控）
- [ ] 播放器：竖屏/全屏切换；暂停时控制栏行为；进度条拖动；选集/画质弹层；返回是否逐层关闭
- [ ] 播放器：**8sp 时间文字在手上是否可读**
- [ ] 短视频：上下滑；右划返回；第 0 页右划不误退应用

### 1.3 搜索/番剧簇
- [ ] 搜索：输入→建议→结果；左右滑分类；**结果页顶部「排序」按钮出现时机**（1.2.7 修复回归测试）
- [ ] 搜索：清空历史（有无确认）；无结果页样式
- [ ] 番剧详情：长标题番剧；选集列表滚动；当前集高亮；从时间线进入后**点标题是否开菜单（而非回时间线）**——确认该语义是否符合预期

### 1.4 动态/消息/评论簇
- [ ] 动态：长文折叠/展开；九宫格图；转发层级
- [ ] 私信：键盘弹出是否顶起输入框；发送失败重发
- [ ] 评论：楼中楼展开；点赞反馈；写评论发送状态

### 1.5 用户/收藏/本地簇
- [ ] 收藏夹列表→详情：批量多选在手机上的按钮可达性
- [ ] 历史/稍后再看：空态文案（emptyTip 是否真的显示）
- [ ] 我的空间：25 处无 contentDescription 图标的信息密度

### 1.6 设置簇
- [ ] **检查更新页**（P1：无顶栏——确认返回键之外是否真的无路可走）
- [ ] **隐私与伪装页**（P1：同上）
- [ ] 菜单设置：改开关→立即杀进程→重开（P1：改动丢失复现）；asyncInflate 未完成时快速返回（NPE 复现需 logcat）
- [ ] 界面设置：「新版美学」开关（重启确认）；「圆屏适配」开启后各页观感；恢复默认（无确认弹窗）
- [ ] 主题色：换一个深色种子（如深蓝）→ 巡检各页：播放量数字、热搜排名、争议角标、进度条**哪些不跟色**（应命中 FB7299 系三处）

### 1.7 登录/引导簇
- [ ] 登录三通道：QR 过期刷新；密码错误文案；短信倒计时
- [ ] 验证码页：WebView 不可用兜底页（白底问题）
- [ ] 首启向导：中途退出重进

## 2. 截图归档约定

存至 `docs/screens/ui-audit-20261105/`，命名 `页面-状态.png`（例：`videoinfo-loadfail.png`）。关键必截：
每个 P1 复现现场、圆屏适配开启后的菜单/列表/播放器三张、主题色自定义后的推荐页。

## 3. 字体缩放 / 小屏模拟（可选但推荐）

- 应用内「设置→界面设置」：边距 H/V 拉到 8-12%（模拟手表可视区缩小）+ density 调整，巡检 §1 各页。
- 系统设置→显示→字体大小调到最大 → 检查 42 处 `layout_height="35sp"` 的按钮/输入框是否爆高（重点：设置主页、写评论、登录表单）。

## 4. logcat 抓取（验证 P1 时同步进行）

```
adb logcat -c && adb logcat AndroidRuntime:E DEBUG:E crash:C *:S | tee crash.log
```

重点观察：SettingMenuActivity NPE（asyncInflate 中退出）、VideoInfoFragment 空白时的异常、短视频页右划退出路径。

## 5. 无法覆盖、需手表实机才能验证的项（未验证清单）

1. 圆形表冠（Rotary 系列）滚动实际手感与事件冲突。
2. W527 类 390x390 及以下分辨率下各页是否溢出（代码按比例推算 6dp 边距可容纳，未证实）。
3. 手表输入法（语音/笔画）在搜索/私信/写评论的可用性。
4. `player_ui_round` 圆屏重排对播放器各弹层（画质/选集）的实际覆盖（代码只重排了 pageName/时钟/刷新按钮）。
5. 低内存手表（<512MB）上 largeHeap + RGB_565 策略是否足够（播放前 clearMemory 已是取舍信号）。

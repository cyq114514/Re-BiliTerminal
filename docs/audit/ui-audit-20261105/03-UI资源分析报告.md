### 1.4 主题引擎覆盖机制（决定自定义主题色能否换干净）

`ThemeApplier`（setContentView 时全树遍历）只替换「精确等于 #FE679A」的白名单控件；`ThemeManager` 派生色算法只接管强调色。**覆盖缺口**：
1. RecyclerView item 需各 Adapter 在 bind 处显式调 `ThemeApplier.apply`——凡漏调的 item 在自定义主题下保持默认粉（已确认 EpisodeCardAdapter/SeasonTabAdapter/HotSearchAdapter 等 Java 硬编码色不在白名单）。
2. `#E75688` 派生（card_bg_highlight）由 ThemeManager 特判处理，但 `card_bg_highlight` 若在布局被直接以 @color 引用则换不到。
3. colorControlActivated 主题属性挂 bili_pink（themes.xml:23）——Classic 回退时切 textwhite，行为正确。

### 2.2 结构性排版问题

- **`layout_height="35sp"` 共 42 处**（sp 当高度单位，随系统字体缩放膨胀）：activity_setting_main.xml、cell_goto.xml、fragment_password_login.xml、activity_write_reply.xml 等 8+ 文件——用户调大字体时按钮高度爆涨挤压列表（布局错乱高危点）。

## 5. 主题系统结构

| 主题 | 用途 | 风险点 |
|---|---|---|
| Theme.BiliClient | 全局默认（MaterialComponents.NoActionBar + windowFullscreen + 永久深色） | 无 values-night——应用即深色单主题（这是设计而非缺失，但需在规范里写死「所有新页面默认深色、禁止假设浅色」） |
| ThemeOverlay.BiliClient.Classic | 关闭新版美学的回退层 | 只覆盖卡片/按钮/激活色——新增组件若未纳入 materialCardViewStyle 体系，Classic 下会漏 |
| Theme.BiliClient.Fullscreen | 短视频页（关 windowSwipeToDismiss） | — |
| Theme.BiliClient.Splash | 开屏背景 | — |
| **Theme.NoSwipe（parent=android:Theme.Black）** | 播放器/看图（非 AppCompat 血统） | **第二主题血统**：自定义 attr（biliCardBackground）必须在此重复补默认值（themes.xml:51-62 已注释）；任何新 attr 忘记补即 inflate 崩溃——结构性风险点 |

## 6. 文案资源

- resConfigs('zh') 单语言；strings.xml 320 行。
- **布局硬编码中文 android:text 共 407 处**（Top：activity_setting_about 28、activity_setting_main 25、activity_setting_ui 18、activity_vip 16、activity_myspace 13、activity_player 13、cell_user_info 13、activity_live_info 12、activity_setting_theme_color 12、fragment_video_info 12）。单语言应用下不影响功能，但阻碍未来多语言与文案统一管理；其中用户可见错误提示混布在 Java（如「还没有登录喵~」）与 strings 两种来源。
- 标题体系：31 个 `pagename_*` 字符串完整覆盖顶栏（含 pagename_default「页面标题」兜底）——机制健全，见页面清单报告 §8。

## 7. 资源结论（供设计规范引用）

1. 颜色：强调粉 5 值并存、次级文字 4 写法、双蓝、暖白/纯白混用 → 规范需先「收口存量」再立 Token。
2. 字号：无阶梯，13/11sp 成事实基准，8-10sp 触底 → 立字号阶梯并设手表最小可读下限。
3. 高度单位：42 处 35sp 当高度 → 统一换 dp 或 minHeight 机制（P2 整改项）。
4. 圆角：10dp(卡)/6dp(图)/3dp(徽标)/16dp(BottomSheet) 四档 + 热搜 2dp 漏网 → 规范明确各档用途。
5. 主题引擎：白名单换色机制优秀但覆盖依赖各 Adapter 自觉 → 新增 item 布局需把「硬编码强调色」列为例行检查项。

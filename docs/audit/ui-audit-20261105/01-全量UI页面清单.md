# Re-BiliTerminal 全量 UI 页面清单

> 审计基线：1.2.8（versionCode 20261103）· 只读静态扫描自动生成 + 人工核对 · 2026-11-05
> 路径约定：`java/` = `app/src/main/java/com/RobinNotBad/BiliClient/`，`res/layout/` 同理。

## 1. UI 架构总览

| 层 | 内容 |
|---|---|
| 基类体系 | `BaseActivity`（主题/边距/dpi 调整/氛围背景/音频胶囊/顶栏返回/圆屏适配/KEYCODE_MENU 返回）← `InstanceActivity`（可恢复页，顶栏点击=开菜单）← `RefreshMainActivity`；`BaseActivity` ← `RefreshListActivity`（activity_simple_refresh 标准列表页） |
| 导航模型 | 菜单辐射式：`MenuActivity.killAndJump()` 跳转各页并 finish 自己；顶栏点击=finish（BaseActivity 页）或=重开菜单（InstanceActivity 页）；冷启动栈恢复由 `SplashActivity`+`ResumePageUtil` 重建 |
| Fragment 基类 | `BaseFragment` ← `RefreshListFragment`（fragment_simple_refresh）；ViewPager 页共用 `activity_simple_viewpager` |
| 弹窗体系 | 自研 `AdaptiveDialog`（适配手表防超屏）全量替代系统 AlertDialog（全仓 0 处残余）；`ShareToMsgDialog`（BottomSheetDialogFragment）；DatePickerDialog/TimePickerDialog 仅发动态定时用 |
| 列表体系 | RecyclerView 为主；自定义 `CustomLinearManager`/`CustomGridManager`（横屏 3 列）；Rotary 系列支持表冠旋转 |

## 8. 标题点击返回专项结论（对应附加需求）

**机制**：顶栏 `R.id.top`（pageName 标题+arrow_back 图标）由 `BaseActivity.onStart()` 自动挂 `setTopbarExit()`（点击=finish）；InstanceActivity 系页面改为 `setMenuClick()`（点击=开菜单）。全部 31 个含顶栏布局都预置了 `pagename_*` 标题文案（strings.xml），标题显示无缺口。

**未达标页面（点击标题无法返回上级）**：

| 页面 | 现状 | 定级 | 依据 |
|---|---|---|---|
| UpdateActivity | 布局无顶栏，仅系统返回键 | **P1** | activity_update.xml（无 @+id/top）+ UpdateActivity.java:41 |
| PrivacyLockSettingsActivity | 布局无顶栏，仅系统返回键 | **P1** | activity_privacy_lock.xml:3-17 + PrivacyLockSettingsActivity.java:53 |
| JumpToPlayerActivity | 布局无顶栏；取流期间点击无效 | P2 | activity_player_jump.xml + JumpToPlayerActivity.java:133-157 |
| TutorialActivity | 布局无顶栏且吞返回（强制阅读，可豁免但需标注） | P2（标注） | TutorialActivity.java:48-64 |
| ShortVideoPlayerActivity | 无顶栏（全屏信息流）；返回=回菜单设计 | P2 | activity_short_video_player.xml + ShortVideoPlayerActivity.java:133-156 |
| DownloadActivity | 下载进度页无顶栏 | P3（半豁免） | activity_download.xml |
| CalculatorActivity / CatchActivity / DialogActivity / GetIntentActivity / SplashActivity | 伪装/崩溃/模态/跳板/开屏 | 豁免 | — |

**语义不一致（影响"返回上级"体验一致性）**：同是点标题，BaseActivity 页=finish（回到来源页），InstanceActivity 页=开菜单（约 17 个页面，含 BangumiActivity、SearchActivity、MySpaceActivity 等）。从非菜单路径进入这些页面时（如 时间线→番剧详情），点标题将打开菜单而非来源页——需要在整改规划中决策：保留（手表菜单即首页范式）或改为智能返回（有来源则 finish）。

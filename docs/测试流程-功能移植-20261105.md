## 1. 分网络默认清晰度（Revival）

入口：`设置 → 播放器选择`，新增「移动数据清晰度」「Wi-Fi 清晰度」两行，右侧显示当前值。

| # | 步骤 | 预期 |
|---|---|---|
| 1.1 | 点「移动数据清晰度」→ 选 720P | 返回后该行显示 `720P`；「清晰度」仍为原值 |
| 1.2 | 点「Wi-Fi 清晰度」→ 选 1080P | 该行显示 `1080P` |
| 1.3 | 关 Wi-Fi、用移动数据打开任意在线视频 | 起播画质为 720P（播放页清晰度按钮显示 720P，非 360P） |
| 1.4 | 连 Wi-Fi 打开同一视频 | 起播 1080P |
| 1.5 | 把「移动数据清晰度」改回「跟随全局」 | 移动数据下起播回到「清晰度」里设的全局值 |
| 1.6 | 播放中手动切清晰度到别的档 | 切换生效，**不会被网络默认值立刻拽回** |
| 1.7 | 开飞行模式后仅开 VPN，再播 | 回退全局默认，不崩、不卡在加载 |
| 1.8 | `设置 → 内置播放器设置` 里的搜索：搜「移动数据清晰度」「Wi-Fi 清晰度」 | 能定位到「播放器选择」页 |

补充口径（代码行为，非猜测）：手动选择永远优先于网络默认；只有 360P/720P/1080P 三档；网络识别不了（VPN 取不到底层网络）走全局值。

## 2. 跳到指定时间（RE）

入口：播放页控制栏的时钟图标按钮（`icon_jump_time`）。

| # | 输入 | 预期 |
|---|---|---|
| 2.1 | `90` | 跳到 1:30 |
| 2.2 | `1:30` | 同上 |
| 2.3 | `01:02:03` | 跳到 1:02:03 |
| 2.4 | `1：30`（全角冒号） | 同上，可正常跳 |
| 2.5 | `99999`（超过片长） | 跳到片尾，不报错 |
| 2.6 | `1:99` | 提示「时间格式不正确」，不跳 |
| 2.7 | `abc` / 空 / `1:2:3:4` | 提示「时间格式不正确」，不跳 |
| 2.8 | 暂停状态下跳转 | 停在目标画面，弹幕不错位、不反复清空 |
| 2.9 | 直播页 | 提示「当前视频不支持跳转到指定时间」或入口无效 |
| 2.10 | 跳转后继续播放 10s | 弹幕与进度条同步（无整体超前/滞后） |

## 3. 横滑调进度灵敏度（RE）

入口：`设置 → 内置播放器设置 → 横滑调进度灵敏度`（默认 `1.0`）。

计算口径：满屏横滑总跨度 = `clamp(片长/6, 30s, 300s) × 灵敏度`。

| # | 步骤 | 预期 |
|---|---|---|
| 3.1 | 不修改设置，长视频横滑到底 | 与改造前手感一致（1:1） |
| 3.2 | 灵敏度设 `0.5`，同样滑动距离 | 跨度约为原来一半（1 小时视频约 150s） |
| 3.3 | 灵敏度设 `3.0` | 跨度约为原来三倍，松手后提示「已跳转到 xx」 |
| 3.4 | 输入 `abc` / `-1` / `99` | 回落 1.0，不出现进度跑飞 |
| 3.5 | 双指放大画面后单指拖动 | 仍是拖动画布，**不触发调进度** |
| 3.6 | 拖动未松手时 | 只显示目标时间提示，松手才真正跳转 |

## 6. 本地缓存断点续播（RE）

入口：`设置 → 内置播放器设置 → 本地缓存续播`（默认开）。

| # | 步骤 | 预期 |
|---|---|---|
| 6.1 | 播本地缓存视频到约 1 分钟 → 返回 → 再进 | 从约 1 分钟处续播 |
| 6.2 | 播到距结尾 <5s 退出 → 再进 | 从头播（视为已看完） |
| 6.3 | 进入后 3s 内退出 → 再进 | 从头播（位置过小不记） |
| 6.4 | 关闭该开关后再走 6.1 | 从头播 |
| 6.5 | 开「隐私模式」后再走 6.1 | 不续播，且目录里的 `.video_meta.json` 时间戳不更新 |
| 6.6 | 文件管理器进入该视频所在目录 | 存在 `.video_meta.json`（隐藏文件） |
| 6.7 | 删除 `.video_meta.json` 再播 | 从头播，不报错 |
| 6.8 | 播放中从最近任务划掉应用，再进 | 从头或续播到最近位置都可接受；**不允许崩溃** |
| 6.9 | 对照组：在线视频、番剧 | 续播行为与改造前完全一致（仍只信服务端进度） |

# 变更记录：右边缘左滑快捷面板改为默认关闭（2026-11-22）

## 背景

用户要求：之前版本新增的“从右向左滑呼出控制面板”改为默认关闭。
该手势在列表横滑、返回手势场景容易误触，弹出“最近观看 / 播放历史 / 稍后再看 / 搜索”面板。

## 改动

| 文件 | 位置 | 改动 |
|---|---|---|
| `BaseActivity.java` | `dispatchTouchEvent` | `getBoolean(QUICK_SWIPE_ENABLE, true)` → `false` |
| `SettingUIActivity.java` | 界面设置页开关 | `setChecked(getBoolean(QUICK_SWIPE_ENABLE, true))` → `false` |

设置项 key 不变（`quick_swipe_enable`），开关仍在「设置 → 界面与外观 → 界面设置 → 右边缘左滑快捷面板」，
用户需要时可以手动打开。

**老用户影响**：只改读取默认值。SP 里已经有显式 `true` 的用户（手动开过）保持开启；
从未设置过的用户从此默认关闭。

## 验证

- 编译 `:app:compileDebugJavaWithJavac` 通过，lint 0 条。
- **真机验证未完成**：打包安装前手机无线调试掉线（`adb devices` 只剩两个 Wear 模拟器，
  mDNS 也搜不到该设备），重连失败；Wear 模拟器为 x86_64，安装 arm64 APK 报
  `INSTALL_FAILED_NO_MATCHING_ABIS`。需在手机上补一次“右边缘左滑不弹面板”的确认。

## 回滚

两处默认值改回 `true` 即可，无其它依赖。

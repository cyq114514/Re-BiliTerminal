# 变更记录：搜索头部触发修复 + 横屏矮屏控制层压缩（2026-11-22）

## 1. A1：fling 不再参与头部方向累计

**问题**：快速滑动（甩动）时顶部栏突然显现。上一轮只改了动画性能，没改触发逻辑。

**根因**：`onScrolled` 在手指抬起后的 `SETTLING` 阶段仍持续收到 dy，快速甩到边界时 dy 反号，
方向累计器达到 48dp 就翻转为“展开”。

**改动**（`SearchActivity`）：

- 新增 `recyclerScrollState`，在 `onRecyclerViewScrollState` 里更新；
- `onScrolled(dy, force)` 的非 force 分支只在 `SCROLL_STATE_DRAGGING` 时累计方向，
  fling 阶段直接清零累计器。

## 2. A2：到顶不再“一按下就展开”

**问题**：列表在顶部时，手指一按下（DRAGGING）就强制展开头部。

**改动**：

- `SearchFragment`：删除 `onScrollStateChanged` 里的 `onScrolled(-114, true)` 强制展开；
- 新增 `RecyclerView.setOnTouchListener`（返回 false 不拦截）：按下时记录起点，
  仅当“头部已收起 + 列表在顶部 + 向下拖过 24dp”才调用 `showHeaderOnPull()`；
- `SearchActivity` 新增 `isSearchBarVisible()` 与 `showHeaderOnPull()`。

**真机验证（PJZ110）**：

| 操作 | 结果 |
|---|---|
| 快速上滑 3 次 | 头部保持收起（不再弹回） |
| 轻拖 10dp | 头部不展开 |
| 下拉 35dp | 头部展开 |

## 3. B1：横屏矮屏（词典笔/点读笔）紧凑控制层

**判定**：`screen_landscape` 且屏幕短边 < 300dp。

**压缩项（只压不藏，避免“藏了却没入口”）**：

| 元素 | 正常 | 紧凑 |
|---|---|---|
| 顶栏电量/时钟 | 显示 | 隐藏 |
| 标题字号 / 顶栏内边距 | 14sp / 6dp | 12sp / 3dp |
| 进度条高度 | 20dp | 14dp |
| 底栏按钮 | 38dp | 30dp |
| 底栏卡片内边距 | 2/4dp | 1/2dp |
| 左侧 ±秒/倍速 | 默认 28dp、下限 20dp | 默认 24dp、下限 16dp |

**可逆**：`applyCompactLandscapeUi()` 先恢复 XML 默认值再按需压缩；
`onConfigurationChanged` 里重新调用（旋转按钮切横屏时不会保留旧态）。
圆屏分支不受影响（字幕宽度仍按 0.65 屏宽）。

## 4. B4：CC 字幕在矮屏的限制

- `text_subtitle` 最大宽度 = 屏幕短边 × 86%（原来非圆屏不限宽）；
- 最多 3 行、末尾省略；
- 字号 10sp（正常 11sp）。

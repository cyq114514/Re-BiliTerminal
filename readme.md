## 为什么要做这个分支

上游「哔哩终端」已经停更归档，而它面向的**低配手机、手表、老设备**恰恰是被主流客户端放弃的一类机器：
官方客户端越更新越重，这些设备要么装不上，要么卡到没法看。

这个分支的起点很具体：**番剧的观看进度记不住、还会串集**——看过第 15 话，点开没看过的第 16 话，
却从第 15 话的位置接着播；在别处（网页端/官方客户端）看过并记着的位置，这里又读不到。
进度是"能不能用得下去"的底线，于是从 1.0.0 开始一路修到现在（`1.2.0fix` 已经把这条链路彻底理清，
技术细节见[更新日志](docs/更新日志.md)）。

在此基础上，本分支持续做三件事：

1. **修坏掉的地方** —— 上游遗留的功能缺陷（进度、评论、搜索、下载、崩溃点）；
2. **补上缺的能力** —— 番剧选集、后台播放、动态增强、多账号、应用内更新；
3. **不改使用习惯** —— 保持 `minSdk 19`、纯 Java + XML、轻量、无广告、不收集账号信息。

目标不是做一个"更好的 B 站客户端"，而是**让那些被扔在抽屉里的老设备还能继续刷 B 站**。

## 这个分支和上游有什么不同

主线功能（视频、直播、动态、消息、收藏等）与上游一致，差别在于：

**新增能力**

- **观看进度按集记住** —— 番剧每集、投稿视频每个分 P 各自记住看到哪，退出重进接着看；
  番剧的进度与服务端（网页端/官方客户端）双向一致
- **番剧选集** —— 多季 / 剧场版 / OVA 在详情页直接切换，自动定位上次看到的那一集，任意一集一键直达
- **后台播放** —— 熄屏或退到后台继续播放，通知栏遥控暂停/继续/关闭，低内存设备不易被系统杀掉
- **切后台回到原页面** —— 应用被系统清理后再次打开，自动回到上次停留的页面（详情页同样支持）
- **动态更完整** —— 带图发动态 / 带图发评论、投票、置顶、可见范围、编辑、话题页，图文动态打开更快
- **多账号切换** —— 登录过的账号自动保存，设置→账号切换一键换号，登录状态自动保持最新
- **应用内检查更新** —— 打开应用自动检查新版本，应用内下载安装（断点续传 + 完整性校验），可切换镜像
- **本机累积记录** —— 经验 / 硬币变化记录在本机累积（B 站接口只提供最近一周），越用越全

**修复与加固（上游遗留问题）**

- **观看进度** —— 串集、读不到服务端记录、切集覆盖、上报静默失效（Cookie 轮换导致的 `-111`）
- **播放稳定性** —— 退出播放页/切清晰度卡死、弹幕时间轴错位、长时观看后闪退、定时任务泄漏
- **评论** —— 评论区偶发卡死、带图评论、子评论卡片样式统一
- **搜索** —— 搜索建议、热搜榜、结果被历史面板遮挡、切后台恢复后重放搜索
- **圆屏/手表适配** —— 播放页按钮被裁切、弹幕按钮显隐不一致、转场动画
- **安全加固** —— 登录凭证不进日志、图片与播放链路不携带会话、更新包强制签名与完整性校验

**明确的边界**

- 只打包 32 位 ABI（与上游一致），纯 64 位设备装不上；
- 编辑动态只支持纯文字；动态侧尚未实现匿名投票、话题页排序等；
- 完整已知问题列表见 [Issues](https://github.com/cyq114514/Re-BiliTerminal/issues)。

## 下载与安装

从 [Releases](https://github.com/cyq114514/Re-BiliTerminal/releases) 下载 `Re-BiliTerminal-<版本>-release.apk`。

| 项目 | 说明 |
| --- | --- |
| 系统要求 | **Android 4.4 及以上**（`minSdk 19`，`targetSdk 26`） |
| 旧设备 | Android 4.0.4–4.3 的设备请安装 `1.1.1` 或更早版本 |
| ABI | `armeabi-v7a`、`x86`（**不含 arm64-v8a**，与上游一致；arm64 设备走 32 位兼容模式） |
| 签名 | 正式证书。同签名版本**直接覆盖安装即可**，无需卸载、不丢登录态 |
| 共存 | 若设备上同时装有原版「哔哩终端」，两者会并存，属正常现象 |

> 本软件永久免费开源，不收集账号与隐私信息。**若你在任何平台付费下载到它，那你被坑了。**

出问题时的排查建议：先到 设置 → 关于 确认版本号；番剧进度相关问题可以在
**设置 → 实验室 → 调试 → 番剧进度诊断** 打开诊断开关（默认关闭），复现一次后把
`Download/ReBiliDiag/progress-diag.txt`（没有存储权限时为 `Android/media/com.RobinNotBad.BiliClient.re/`
下的同名文件）附在 Issue 里。

## 构建

```bash
git clone https://github.com/cyq114514/Re-BiliTerminal.git
cd Re-BiliTerminal
# 需要 JDK 17+ 与 Android SDK（compileSdk 33）
./gradlew :app:assembleDebug     # 调试包
./gradlew :app:assembleRelease   # 正式包（需自行配置签名）
```

Release 签名通过项目根目录的 `local.properties` 读取（该文件已在 `.gitignore` 中）：

```properties
sdk.dir=/path/to/Android/sdk
KEY_PATH=/path/to/your.jks
KEY_PASSWORD=******
ALIAS_NAME=******
ALIAS_PASSWORD=******
```

> **`KEY_PATH` 必须是纯 ASCII 路径。** `local.properties` 会被 `Properties.load()`
> 按 ISO-8859-1 解析，路径里一旦含中文就会读成乱码，导致 `validateSigningRelease`
> 报 `keystore file not found`。

推送 `v*` 标签会触发 [CI](.github/workflows/ci.yml) 自动构建正式包、创建 Release 并生成
应用内更新所需的 `update.json`（签名密钥以仓库 Secrets 提供：`KEYSTORE_B64`、
`KEY_PASSWORD`、`ALIAS_NAME`、`ALIAS_PASSWORD`）。

## 技术栈

- **语言 / 界面**：Java + XML（`minSdk 19`，无 Kotlin、无 Compose）
- **播放器**：`ijkplayer-java`（模块内置，源自 [bilibili/ijkplayer](https://github.com/bilibili/ijkplayer)）
- **弹幕**：`DanmakuFlameMaster`（模块内置，已打本地补丁）
- **网络 / 解析**：OkHttp 3.12.13 · Gson 2.8.9 · protobuf-javalite（弹幕协议）
- **其他**：Glide、EventBus、jsoup、PhotoView、zxing、Brotli（`brotlij` JNI 模块）

## 已知问题

- 观看进度依赖服务端接口，**未登录时不会上报**（日志中会有明确提示）。
- B 站对"本季最近观看"只维护一条记录（服务端行为，官方客户端同样如此）；本分支改为按集读取每集自己的进度，
  但仍以服务端数据为准：某集在服务端确实没有记录时，只能从头播。
- 使用外部播放器（小电视 / 凉腕）时拿不到播放结束时的真实进度，会用进入播放前的进度兜底。
- 部分界面文案（如初始引导页里的 QQ 群与官网信息）**仍沿用上游**，未随本分支更新。
- 只打包 32 位 ABI（`armeabi-v7a`/`x86`），**纯 64 位设备无法安装**（报 `INSTALL_FAILED_NO_MATCHING_ABIS`；Pixel 7 起 Tensor 设备、2023 年后部分新机已移除 32 位运行时，此范围还在扩大）。
- 编辑动态仅支持**纯文字**动态；带图、带转发内容的动态暂不支持编辑。
- 图片评论依赖评论区开启该功能，楼中楼（子评论）不支持带图。
- 动态侧尚未实现：投票创建、匿名投票、话题页排序切换。

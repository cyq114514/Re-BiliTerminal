隐私说明

最后更新：2026-10-17 · 适用于 1.2.1 及以后版本

一句话概括

本应用不收集账号、不采集浏览与搜索记录、不含广告与统计分析。 唯一会上传的是崩溃现场（用于定位闪退），默认开启、可随时关闭。

不收集什么

  • 不上传 B 站账号、Cookie、登录凭证
  • 不记录你看了什么、搜了什么、收藏了什么
  • 不采集 IMEI / OAID / AndroidID / MAC 等设备唯一标识
  • 不读取通讯录、短信、相册、位置
  • 应用内没有广告 SDK，也没有第三方统计 SDK

崩溃上报

用途只有一个：闪退时把现场发回来，才能定位并修掉。1.2.1 起默认开启， 首次安装或升级时会弹窗说明一次。

字段内容用途
stacktrace崩溃堆栈定位到具体代码位置
exception_class / message异常类型与消息归类同类崩溃
app_version应用版本号判断是否为旧版本问题
android_version / sdk_int系统版本排查系统兼容性
device_model机型排查特定机型问题
page崩溃时所在页面缩小复现范围
thread_name崩溃线程名区分主线程/工作线程
install_id本地随机生成的 UUID统计影响设备数，与账号无关

存储位置：Supabase 提供的数据库（区域 ap-southeast-1，新加坡）。 这意味着崩溃数据会出境存储，如果你不接受，请按下一节关闭上报。

如何关闭

  • 设置 → 偏好设置 → 崩溃上报，关掉即停止联网上报，立即生效；
  • 首次安装/升级时的弹窗里也有「关闭上报」按钮；
  • 关闭后崩溃页仍会显示，但不再发送任何数据。

本机留存的记录

无论是否开启上报，每次崩溃都会在本机留一份文本记录，方便你自己查看或反馈时提供： Download/ReBiliDiag/crash-*.txt；该目录不可写时回落到 Android/media/<包名>/。最多保留 20 份，超出自动删除最旧的。

权限说明

权限用途
INTERNET访问 B 站接口、检查更新、崩溃上报
ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE判断网络是否可用，弱网时提示
READ / WRITE_EXTERNAL_STORAGE旧版系统上下载视频、导出日志与崩溃记录
FOREGROUND_SERVICE / POST_NOTIFICATIONS后台播放与下载的常驻通知
REQUEST_INSTALL_PACKAGES应用内更新时调起系统安装器
VIBRATE按压反馈

本网站

本页面是纯静态站点：不使用 Cookie、不接入访问统计、不投放广告、不加载任何第三方脚本或字体。

第三方库

OkHttp、Glide、PhotoView、Jsoup、EventBus、IJKPlayer、DanmakuFlameMaster 与 AndroidX。 完整清单见应用内「设置 → 关于」。这些库均在本地运行，不上报数据；唯一的联网上报就是上文的崩溃上报。

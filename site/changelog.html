1.3.6

2026-11-14 · versionCode 20261116
  • 修复后台请求误报网络错误：视频能正常播放时，观看进度上报、在看人数、字幕列表、旧版弹幕这些后台请求一旦失败，会弹「网络错误」让人以为整段播放断了。现在这类失败只记日志，字幕类改说「字幕加载失败」。
  • 修复缓存音频只播一首：从缓存页点音频条目，播完第一首就停；现在整组连播，播完最后一首回到第一首（本地条目此前被当成无效项整批丢弃）。
  • 后台通知不再每秒重刷：开「后台/熄屏继续播放」时，通知栏每秒都在重建刷新，暂停了也照刷。现在只有内容真的变化才更新——停在表盘上的通知不再白耗电。
  • 直播列表滚动更跟手：每张卡片原先都要在主线程把标题做一次完整的 HTML 解析，现在一间房只解析一次。
  • 自定义主题色全线跟随：播放器选中描边、收藏夹描边、历史分P高亮、互关徽章底、播放中声波图标，此前写死旧版粉，换主题不跟随；现在统一走强调色。
  • 搜索页头部一起收起：搜索框滑走后，分类页签会单独留在顶上白占一行；现在两者合成一个头部整体收起/展开。
  • 触控与字号收尾：听歌页音量键 36dp → 40dp（圆表上不易误触）；BGM 专题、关于页、音频入口卡的 10sp 小字放大到 11sp。

1.3.5

2026-11-08 · versionCode 20261115
  • 修复分组视图的互关徽章：关注列表切成「分组」后，互关用户头像旁的徽章消失了——分组数据里没有关系字段，现已单独补齐。
  • 修复老设备闪退：Android 4.4 设备上打开「主题配色」会直接退出。
  • 修复动态红点：1.3.4 说修好了，实际刷新后 UP 主头像上的小红点仍在；这次真正清掉。
  • 修复放大后播放器底部按钮消失：「界面大小」调大后，底部那一排按钮会整排不见——收缩逻辑取错了控件层级，把整行压成了 24dp。
  • 修复放大后安装按钮点不到：「检查更新」页正文可滚动，安装按钮固定在屏幕底部。
  • 收藏夹更省地方：「听全部」「下载全部」两张卡片在小屏/手表上只保留一行标题。
  • 收藏夹头部跟手：卡片和排序栏随列表同步滑动，不再「滚过一整屏突然收起」。
  • 修复分类标签遮挡：搜索结果的分类标签在字体放大后不再压住第一条结果。
  • 修复回首页图标位置：视频详情页顶栏的房子图标与标题文字对齐。
  • 表冠缩放灵敏度可调：设置 → 实验室新增两个输入项，默认手感和以前一样。
  • 长按加速有提示：长按画面加速时，屏幕中间提示「3x 加速中，松手恢复」。
  • 修复弹幕整屏消失（11-14 补充）：手表或长视频下，弹幕会时不时整屏消失、过一会儿又冒出来。根因是弹幕的时间轴和播放进度是两套时钟，一对不上就得跳转，而跳转必然清屏；现在弹幕改成跟着播放进度走，不再需要跳转。
  • 修复长按加速后的后遗症：加速过一次，即使松手恢复原速，弹幕仍会周期性地整屏消失；现在不会再残留。
  • 长按加速时弹幕原地变速：屏幕上正在飘的弹幕当场加速、松手当场恢复，不会整批重来，也不用等它飘完。
  • 新增「弹幕按播放位置驱动」开关：设置 → 实验室，默认开启；万一有异常可一键切回旧实现。
  • 开屏与强调色跟随背景图（11-14 补充）：在「设置 → 界面」选了自定义背景图后，如果没手动选过主题配色，界面强调色和开屏光晕会自动取背景图的主色；灰阶/纯黑白图会回退默认粉。另外冷启动第一帧不再先闪一下固定粉光。

1.3.4

2026-11-08 · versionCode 20261110
  • 直播可以发弹幕：播放页的弹幕框在直播下改走直播接口，发送成功本地即时上屏（直播弹幕的接收展示仍暂未开放）。
  • 选集弹窗分组与倒序：全部选集支持按分区标题分组、可切「倒序显示」，正片/预告/PV 一目了然，最新一话在最上；详情页外观不变。
  • 选集卡片：番剧选集卡片换成与视频卡片一致的半透明风格（半透明灰底 + 圆角 + 细描边）。
  • 修复长视频 66 分钟后没有弹幕：分段数一直按「兜底 1 小时」计算（11 段 × 6 分钟 = 66 分钟），且真实时长在页面跳转时丢了；现在按视频真实时长取满，中间某几分钟没人发弹幕也不会提前中断。
  • 修复高能进度条只画到一半：波形原本只算到最后一条弹幕的时间，片尾就断了；现在铺满整条进度条。
  • 修复私信重复：发一条却连弹好几条相同的消息——同一时刻只允许一次拉取，重复消息按序号过滤。
  • 修复动态红点：动态页点刷新（按钮或下拉）后，UP 主头像上的小红点按已读清掉。
  • 顶栏更清爽：播放页右上角改成「时间 + 电量百分比」一行，去掉了电池图形，不再挤成一团。
  • 收到的赞：只显示头像，不再在头像旁显示昵称（内容里已经写了「赞了你的…」）。
  • 修复短视频自动熄屏：短视频的保屏调用对 TextureView 是空操作，已在页面挂保屏。
  • 修复短视频退回桌面：拉出菜单再关掉会退到桌面，现在关菜单回到短视频。
  • 修复圆屏「回首页」按钮：视频详情页的按钮会压住或远离居中的标题，现在贴在标题右侧。
  • 修复底部图标被裁：小屏或「界面大小」放大后，播放器底部一排图标被屏幕左右边缘裁掉——放不下时整行等比收缩。
  • 接口错误提示：关注/粉丝/粉丝勋章加载失败时显示服务端真实原因（此前统一显示「解析错误」，无法区分 token 过期与风控）。
  • 音量键与无极调音：播放页、听歌页、短视频都支持硬件音量键——单击加减一档并提示百分比，按住 600ms 弹出无极调音（0~100%，1% 一档）。听歌页和短视频页另有屏幕上的 −/＋ 音量键；听歌页的键与滑条分两行，不会互相遮挡。
  • 短视频调音量：短视频「更多」里新增「音量」。
  • 发送缓冲：评论 / 私信 / 动态三处加 3 秒窗口，连点只发一条并提示「请勿频繁点击」；发送失败可立刻重试。
  • 启动首页：设置 → 偏好设置 → 功能 →「启动首页」可指定开屏进哪一页（如「我的」），选定后没网也照样进。
  • 低电量提醒：电量低于阈值（默认 20%，可选 5/10/15/20/30%）时发通知提醒充电。
  • 表冠缩放：设置 → 实验室可开启「表冠缩放图片 / 表冠缩放视频」，默认关闭。
  • 私信体验：气泡上方显示发送时间；「私信可能被拦截」提示可点「不再提醒」，设置里能重新打开。
  • 修复直播发不了弹幕：功能早已实现，但直播模式把「更多」按钮一起隐藏了，而发弹幕按钮在它展开的菜单里——现在直播下可直接发。
  • 修复用户主页看不到人：没有动态时整页被替换成一句空态，个人信息一起消失；改为在列表里追加一条占位。
  • 修复计算器圆屏难用：数字区改为 3 列 4 行、运算符单独一列，显示区缩小，按键变大。
  • 修复「更多」溢出屏幕：展开的按钮行按屏幕宽度自适应，功能再多也不会被顶出屏幕。

1.2.9

2026-11-05 · versionCode 20261105
  • 番剧分区：主菜单新增「番剧」入口（设置 → 菜单 可关闭）——推荐 / 追番 / 索引 / 新番 四页签，索引支持排序与动态筛选，页签与筛选栏会随列表滚出屏幕。

  • 分网络默认画质：Wi-Fi 与移动数据可分别设定默认清晰度，手动切过的清晰度仍然优先。
  • 播放页精确控制：新增「跳到指定时间」（90 / 1:30 / 01:02:03 都行）与「横滑调进度灵敏度」（0.25x~3x，默认手感不变）。
  • 详情页内容增强：AI 视频摘要（需登录）、只读视频笔记。
  • 本地缓存断点续播：缓存的视频看到一半退出，下次从原位置继续。
  • 修复收藏夹闪退：下拉刷新或编辑返回时偶发的 Inconsistency detected 崩溃，根因是列表数据在后台线程被清空而界面仍在读。
  • 修复播放页闪退：点「跳到指定时间」时弹窗主题与播放页不匹配导致崩溃。
  • 修复手表上的小黑点：背景光晕的渐变圆心是数学奇点，个别 GPU 会在该像素画出黑点，圆心已移到屏幕外。
  • 修复顶部白条：列表滑到头时的拉伸发光由近白色改为卡片描边色。
  • 交互改进：听歌页封面与控制按钮按屏幕比例自适应；收藏夹排序改为胶囊并按滚动收起；「听全部」改成与视频卡片同款的半透明卡片；播放队列长标题显示两行。
  • 听歌快速加载：预取下一首并把听过的音频缓存到本地，切歌和拖进度条都更快；最多占用约 80MB，首次使用会说明，可在设置里关闭。
  • 听歌进度记忆：同一个收藏夹再点「听全部」会从上次听到的地方继续；隐私模式下不记录。
  • 听歌页歌词：优先用 B 站字幕，没有字幕时自动按歌名搜网易云歌词；带轻量换行动画，匹配不上就不显示，不会配错。
  • 下载全部（音频）：收藏夹一键把整个夹子加入音频下载队列，后台逐个下载，已下载的不会重复。
  • 修复切歌连跳 / 音画不同步：切歌会连跳两三首、拖进度条后声音和进度条对不上——旧播放器的回调串到了新歌上。
  • 修复番剧开关：设置里「显示番剧」开关点了没反应（开关没接上），现在可以正常控制菜单入口。
